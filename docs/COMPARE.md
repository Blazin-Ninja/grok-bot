# Visual gap: before → after

Honest note: this is still a procedural Three.js village, not AAA Clash of Clans parity. The pass closes the *language* gap — bright field, walled compound, chunky buildings, readable troops, mobile HUD.

| Clash cue | Before (dusk demo) | After (this pass) |
| --- | --- | --- |
| Lighting | Low sun, orange dusk, long gothic shadows | High midday sun, warm-white key, green bounce, light haze |
| Ground | Dark circular platter, muddy rays | Lush saturated grass, tan dirt paths, slight height noise |
| Layout | Tiny floating poker-chip island | Square-ish walled compound + outer meadow + south gate |
| Buildings | Sharp low-poly blocks, sparse trim | Painted plaster/stone, wood belts, roof tiles, glowing windows, banners |
| Props | Thin tree ring, few rocks | Trees, pines, bushes, flowers, path stones, wall merlons — outside the build grid |
| Units | Small abstract blobs / capsules | Imp (horns, wings, tail), worg (snout, ears), ogre (tusks, club) |
| UI | Thin dark gothic pills | Bold gold resource chip, building thumbnails, colored raid cards with counts |
| Camera | Tight on the keep | Pulled-back iso so the whole hold reads like a village screenshot |

Gameplay (place / upgrade / raid / localStorage economy) is unchanged. Names stay fantasy: Stone Keep, Mana Crystal, Dragon Vault, Warding Tower, Imp / Worg / Ogre.
